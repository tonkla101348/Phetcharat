# ห้างทองเพชรรัตน์ (Phetcharat Gold Shop Management System)

ระบบบริหารจัดการร้านทองครบวงจร (จำนำทอง • คนหลุดจำ • บัญชีรายรับ-รายจ่าย 2569 • สต๊อกทอง 48 ช่อง) พร้อมฐานข้อมูล SQLite และระบบเชื่อมต่อเขียนข้อมูลกลับไปที่ Google Sheets เดิมแบบ Real-Time

## ความสามารถหลัก (6 แท็บ)

1. **ภาพรวมร้าน & ปี 2569** — สรุปยอดเงินต้นจำนำคงค้าง, รายรับ-รายจ่ายสุทธิ, มูลค่าสต๊อกทอง, และตารางเทียบรายเดือนปี 2569
2. **จำนำทอง** — ค้นหาตั๋วจำนำ, รับจำนำใหม่ (รันเลขที่ตั๋วอัตโนมัติ), ต่อดอก / ไถ่ถอน / ลดต้น / เพิ่มยอดจำ พร้อมลงบัญชีให้อัตโนมัติ
3. **คนหลุดจำ** — คำนวณตั๋วที่เกินกำหนด 4 เดือนนับจากวันต่อดอกล่าสุด (หรือวันรับจำนำ) แบบเดียวกับสูตรใน Google Sheets
4. **บัญชีรายรับ-รายจ่าย** — แสดงเดินบัญชีรายวันและยอดสะสมแยกตามแท็บเดือน (เม.ย. – พ.ย. 2569) พร้อมเพิ่มรายการใหม่ก่อนหน้าแถว `สรุปวัน`
5. **สต๊อกทอง (Stock)** — ตาราง 48 คอลัมน์ / 14 หมวดน้ำหนัก (`ทองเก่า 90`, `ทองเก่า 96.5`, `1 กรัม` – `10 บาท`, `ทอง 90%`, `18K`, `เพชร`, `ทอง 99.99%`, `ต่างๆ`) บันทึกเข้า / ออก / ออมทอง รายวัน
6. **เชื่อมต่อ Google Sheets แบบ Real-Time** — ส่งคิวการแก้ไข (`sync_queue`) กลับไปที่ Google Sheets ผ่าน Google Apps Script Web App หรือ Service Account พร้อมปุ่มดึงข้อมูลล่าสุด

## เริ่มใช้งานด่วน (Quick Start)

- ต้องใช้ **Node.js `>= 22.5.0`** (ใช้ `node:sqlite` และ `node:zlib` ในตัว ไม่ต้องลง `npm install`)
- ดับเบิลคลิก **`start.bat`** หรือรันผ่านเทอร์มินัล:

```bash
npm start
# หรือ
node server.js
```

จากนั้นเปิดเบราว์เซอร์ที่ **http://localhost:3456**

## โครงสร้างโปรเจกต์

```text
├── start.bat                   # ตัวรันโปรแกรมบน Windows และเปิดเบราว์เซอร์อัตโนมัติ
├── server.js                   # HTTP & REST API Server (พอร์ต 3456)
├── package.json                # ข้อมูลโปรเจกต์และสคริปต์ start / seed
├── src/
│   ├── db.js                   # ฐานข้อมูล SQLite (data/petcharat.db) และ Business Logic
│   ├── xlsxParser.js           # ตัวอ่านไฟล์ .xlsx และแปลงวันที่ พ.ศ. 69 -> ค.ศ. 2026
│   └── googleSync.js           # ตัวจัดการคิว Sync (Apps Script / Sheets API v4 / Pull)
├── google-apps-script/
│   └── Code.gs                 # โค้ด Google Apps Script สำหรับ Real-Time Write-back
├── public/
│   ├── index.html              # หน้าเว็บหลัก 6 แท็บ + หน้าต่าง POS
│   ├── styles.css              # สไตล์ชีต UI
│   └── app.js                  # Logic ฝั่งหน้าเว็บ
└── data/
    ├── petcharat.db            # ฐานข้อมูล SQLite ที่นำเข้าข้อมูลเริ่มต้นแล้ว
    └── snapshots/              # ไฟล์ .xlsx ต้นฉบับจาก Google Sheets ทั้ง 3 ไฟล์
```

## วิธีเปิดใช้งาน Real-Time Write-Back ไปยัง Google Sheets

1. เปิด Google Sheets ไฟล์ใดไฟล์หนึ่งใน 3 ไฟล์ (แนะนำไฟล์ **จำนำทอง เริ่ม 4818**)
2. ไปที่เมนู **Extensions (ส่วนขยาย) → Apps Script**
3. นำโค้ดจากไฟล์ `google-apps-script/Code.gs` ไปวางทับและกดบันทึก (`Ctrl+S`)
4. กด **Deploy → New deployment** เลือกชนิดเป็น **Web app**
   - **Execute as**: `Me`
   - **Who has access**: `Anyone`
5. คัดลอก **Web app URL** ไปวางในแท็บ **"เชื่อมต่อ Google Sheets"** ของโปรแกรมที่ `http://localhost:3456` แล้วกดทดสอบการเชื่อมต่อ
